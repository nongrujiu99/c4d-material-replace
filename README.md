# C4D 2023 批量材质替换（等同 Alt 拖拽，一次换全场）

把一个材质球丢到已有材质标签的对象上、按住 **Alt** 再松手，C4D 会把标签里的**材质引用**换掉，
不新建标签、不复制任何参数贴图。这个工具做的就是同一件事，只是**一次处理整个工程**。

| | 手动 Alt 拖拽 | 本工具 |
| --- | --- | --- |
| 改的东西 | 标签里的材质引用 | 完全相同（`TEXTURETAG_MATERIAL`） |
| 材质内容 | 不动 | 不动 |
| 标签自身设置 | 不动 | 不动（投射、UV、平铺、选集全保留） |
| 范围 | 拖一个对象 | 整个工程所有引用它的标签 |
| 撤销 | 一步 | 一步（Ctrl+Z 全回退） |

只换引用、不读材质内容，所以 **Redshift 节点材质、Octane、Arnold、标准材质全都一样有效**。

## 一、一键安装

仓库地址：**https://github.com/nongrujiu99/c4d-material-replace**

**Windows（PowerShell）** — 复制这一行执行：

```powershell
git clone https://github.com/nongrujiu99/c4d-material-replace.git && cd c4d-material-replace && powershell -ExecutionPolicy Bypass -File .\install.ps1
```

**macOS / Linux（终端）**：

```sh
git clone https://github.com/nongrujiu99/c4d-material-replace.git && cd c4d-material-replace && sh ./install.sh
```

安装脚本会自动找到本机所有 Cinema 4D 的用户脚本目录（每台电脑的名字带不同哈希后缀，不用自己找），把 `材质替换.py` 复制进去；已有同名文件会先备份成 `.bak`。脚本不联网、不提权、不写注册表。

装完后 **重启 C4D** → 菜单 **脚本（Script）** → **材质替换**。想绑热键：**编辑 → 设置 → 自定义命令**，搜「材质替换」。

手动安装方式见 [第九节](#九拷到别的电脑--别的版本)。

## 二、界面

```
┌───────────────────────────────┐
│ 源   [▣ 白色1          ▾] [拾取] │
│ 目标 [▣ 橙色           ▾] [拾取] │
│ [ 替换 ] [ 交换 ] [ 清空 ]        │
└───────────────────────────────┘
```

- ▣ 是链接框**自带的官方小图标**（不自绘预览），材质名在右侧。
- 每行三格：标签 → 链接框 → 拾取（紧贴链接框吸管后面，点它取材质管理器当前选中项）。
- 底部三个按钮并排一行：替换、交换、清空。关窗点标题栏的 **×**。
- **没有结果框**：执行结果写进窗口标题（如 `材质替换 · 替换 2 个标签 → 橙色`）和 C4D 状态栏，出错才弹窗。
- 窗口 224×108，只有三行。

## 三、操作

1. 源材质拖进第一行链接框，目标材质拖进第二行。
2. 点 **替换**。
3. 看标题栏 / C4D 状态栏的反馈，如 `替换 15 个标签 → 橙色`；出问题会弹窗提示。
4. 后悔：**Ctrl+Z 一次**全部回退。

## 四、行为

- 只写 `tag[c4d.TEXTURETAG_MATERIAL]`，包在 `StartUndo/EndUndo` 里，单步撤销。
- 标签的投射方式、UV 标签、偏移/平铺、选集原样保留（有专门测试锁住）。
- 遍历整个工程，含任意层级的子对象；层级、实例、克隆器都不受影响。
- **正常成功不写硬盘**；只有切换失败或没换全时才写一份 `材质替换_诊断.log`，路径显示在 C4D 状态栏。

## 五、已知边界

| 情况 | 表现 |
| --- | --- |
| 只处理纹理标签 | 材质若被别处引用（如另一个材质着色器里的材质链接），不会跟着换 |
| XRef / 外部引用里的对象 | 属于另一个文档，不在遍历范围 |
| 旧材质球 | 替换后如果已无人引用，它仍留在材质管理器里，需要你手动删（界面不再提供这个勾选） |
| 链接框拖不进材质 | 极少数版本差异；点行尾的「拾取」效果一致 |

## 八、排错

| 现象 | 含义 |
| --- | --- |
| 「旧材质剩余引用 > 0」 | 有标签没切成功，看日志里「切换失败」那几行 |

## 九、拷到别的电脑 / 别的版本

### 只要一个文件

`材质替换.py`（脚本版）就是完整程序，单文件、无依赖、不读外部配置。拷过去就能用。

### 目标机器怎么装

**方式 A：当脚本用（推荐，零权限）**

1. C4D 里 **编辑 → 设置 → 打开配置文件夹**
2. 进 `library\scripts\`，把 `材质替换.py` 丢进去
3. 重启 C4D，菜单 **脚本 → 材质替换**

**方式 B：当插件用（要管理员权限）**

1. 新建文件夹 `...Maxon Cinema 4D 20XX\plugins\MaterialReplace\`
2. 把 `MaterialReplace.pyp` 放进去
3. 重启 C4D，菜单 **扩展 → 材质替换**

> 配置文件夹名字带一串安装哈希，例如
> `Maxon Cinema 4D 2023_XXXXXXX`，每台电脑、每个版本都不一样，
> **不要照抄路径**，从软件里「打开配置文件夹」进去最稳；
> 或者直接跑第一节的一键安装脚本自动探测。

### 版本兼容

代码只用了 R16 就存在的老接口，没有 f-string、没有类型注解、没有版本专属特性：

| C4D 版本 | Python | 情况 |
| --- | --- | --- |
| R23 – 2026（含 2023/2024/2025） | 3.x | **可用**，接口全在 |
| R21 及更早 | 2.7 | 未测试。语法上能过，但中文和 unicode 处理有风险，建议先拿一份工程试 |

用到的接口清单（全部长寿命）：`RegisterCommandPlugin`、`GeDialog`、
`CUSTOMGUI_LINKBOX`、`BaseContainer`、`DescID`、`BaseMaterial`、
`TEXTURETAG_MATERIAL`、`StartUndo/AddUndo/EndUndo`、`StatusSetText`、
`modules.graphview.GvNode`。

### 跨版本还要注意

- **工程文件本身跨版本没问题**：插件只改标签里的材质引用，不碰文件格式、不存盘。
- **渲染器无关**：Redshift / Octane / Arnold / 标准材质都只是换引用，不读不改节点图。
- **插件 ID 固定** `1056001`：同一台机器别同时装两份，会冲突。
- **老版本 C4D 的「扩展」菜单**叫「插件」，位置一样。
